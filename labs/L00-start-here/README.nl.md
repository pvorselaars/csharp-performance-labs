# Lab 0: begin hier

De hele cyclus, één keer, met de antwoorden al ingevuld, zodat je weet hoe "klaar" eruitziet voordat je er alleen voor staat.

**Skills:** Een uitgewerkt voorbeeld met elk template ingevuld, plus de basisleeslijst.

**Mastery checkpoint:** Je kunt zeggen wat een goede log-entry bevat en waarom de hypothese wordt opgeschreven vóór de fix; je kunt uitleggen waarom een gen0 GC goedkoop is en een gen2 GC niet; je kunt zeggen wat Tier 0, Tier 1 en OSR elk doen en waarom de harness opwarmt voordat hij iets timet (zie de [runtime-gids](../../docs/RUNTIME.md)).

Draai er één: `dotnet run -c Release --project labs/L00-start-here/exercises/<id>` (verwacht `FAIL`), werk hem uit zoals beschreven in de [top-level README](../../README.md), en open pas daarna de oplossing.

**Verder lezen:** [Lab 0-leeslijst](../../docs/READING-LIST.md#lab-0-foundations)
