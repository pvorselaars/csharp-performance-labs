# Lab 13: hosting & deployment

Het spul dat pas zichtbaar wordt zodra je het ding daadwerkelijk deployt: connection-afhandeling, logging op het request-pad, GC-configuratie.

**Vaardigheden:** Connection-gedrag en telemetriekosten.

**Mastery checkpoint:** Onderbouw elke hosting-instelling met een meting.

Draai er één: `dotnet run -c Release --project labs/L13-hosting/exercises/<id>` (verwacht `FAIL`), werk hem uit zoals beschreven in de [hoofd-README](../../README.md), en open pas daarna de oplossing.
