# Lab 14: productie-capstones

Alles, gestapeld, onder belasting: zo dicht bij een echt incident als deze repo komt. Schrijf de post-mortem alsof het je werkelijk is overkomen.

**Vaardigheden:** Gestapelde defecten, elk verbergt de volgende; de post-mortem schrijven.

**Mastery checkpoint:** Draai een loadtest die je kunt verdedigen.

Draai er een: `dotnet run -c Release --project labs/L14-capstones/exercises/<id>` (verwacht `FAIL`), werk hem uit zoals beschreven in de [top-level README](../../README.md), en open pas daarna de oplossing.
