# Lab 7: boss fights

Alles uit Labs 1–6, gestapeld: fix het defect dat je kunt zien, en het volgende zat er recht achter verstopt.

**Skills:** Meerdere op elkaar inwerkende problemen; het oplossen van het ene legt het volgende bloot. Alleen het symptoom, geen hints per defect.

**Mastery checkpoint:** Los er één op zonder hints en schrijf de post-mortem.

Draai er één: `dotnet run -c Release --project labs/L07-boss-fights/exercises/<id>` (verwacht `FAIL`), pak hem aan zoals beschreven in de [top-level README](../../README.md), en open pas daarna de oplossing.

**Verder lezen:** [Lab 7 leeslijst](../../docs/READING-LIST.md#lab-7-boss-fights)
