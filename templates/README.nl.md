# Templates

Twee lege formulieren, per poging gekopieerd, nooit ter plekke bewerkt:

- **`LAB-LOG.md`**: één item per exercise-poging: baseline, hypothese (geschreven voordat je code aanraakt), wat je veranderde, resultaat, en de verrassing. Zie de sectie "Hoe je een exercise aanpakt" in de top-level [README.md](../README.md) voor wanneer je dit invult.
- **`POSTMORTEM.md`**: één verslag per eindbaas-gevecht en capstone (Lab 7, en de ASP.NET Core-capstones), geschreven *voordat* je de oplossing leest. Een blaamvrij format: beschrijf het systeem, niet jezelf.

Ingevulde voorbeelden van beide (zodat je ziet hoe "klaar" eruitziet voordat je het zelf produceert) staan in [docs/worked-example/](../docs/worked-example/README.md): [LAB-LOG-example.md](../docs/worked-example/LAB-LOG-example.md) en [POSTMORTEM-example.md](../docs/worked-example/POSTMORTEM-example.md).
