# Lab log

Kopieer de template per poging. Het lijkt bezigheidstherapie; dat is het niet. De waarde zit in de regels **hypothese** en **verrassing** - daar wordt je intuïtie daadwerkelijk gekalibreerd. Wees eerlijk over verkeerde gokken; een log dat alleen de juiste gokken bijhoudt, leert je niets.

```
## L?-?? naam, datum

#### Baseline
? ms / ? MB / gen0-1-2 = ?-?-?

#### Profiler + modus

#### Wat ik zag

#### Hypothese

#### Verandering

#### Resultaat

#### Verrassing

#### Hints gebruikt
0 / 1 / 2 / 3

#### Kon ik het in 2 minuten aan iemand anders uitleggen?

#### Waar zou dit bijten in een echt systeem?

#### Breek mijn eigen fix

```
